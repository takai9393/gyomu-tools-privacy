LandWorks 業務ツール プライバシーポリシー

LandWorks 業務ツール（以下「本アプリ」）は、髙井大輔が自分の業務のためだけに使う個人用のツールです。一般の方には提供していません。

  • 利用する情報：本人の Gmail（メールの読み取り、下書きの作成）と Google カレンダー（予定の読み取り・登録）
  • 利用の目的：本人の業務メールの整理、期限の管理、メールの下書きの作成に限ります。
  • 保存：取得した情報は本人のパソコンと本人の Google ドライブにだけ保存します。第三者への提供・販売は行わず、広告にも使いません。
  • 本アプリによる Google API から受け取った情報の利用と移転は、Google API サービスのユーザーデータに関するポリシー（限定使用の要件を含む）に従います。
